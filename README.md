# Jabal Menu Elegance

"Build a high-end, professional digital menu website for 'Jabal Restaurant' (مطعم جبل) from scratch. The design must be exactly as elegant as a premium restaurant menu.
1. Design Identity:
 Colors: Deep forest green background (#052c1e), elegant white text, and luxurious gold accents (#ffbd59).
 Typography: Strictly use the 'Lemonada' font for everything.
 Header: Sticky top navigation with links (الرئيسية, القائمة, عن المطعم, تواصل), with a space for the logo in the center and a 'Call/Order' button.
2. Sections to Build:
 Hero Section: Title: 'نكهات غريبة بطعم مختلف', Description: 'في مطعم جبل، نقدّم تجربة طعام تجمع بين الفن الغربي والذوق الشرقي، من الستيك المشوي إلى البيتزا الإيطالية، كل طبق يُحضّر بشغف ومكونات طازجة.', Buttons: 'تصفح القائمة' & 'للطلبات'.
 About Section: Title: 'قصتنا تبدأ بشغف', Text: 'مطعم جبل ليس مجرد مطعم – إنه وجهة لمحبي الطعام الراقي في البصرة. نختار مكوناتنا بعناية، ونحضّر أطباقنا بحب، لنقدّم لك تجربة لا تُنسى مع كل لقمة.', with stats icons (8+ قسم, 5+ طبق, 5 تقييم).
 Menu Sections: Create large, beautiful image-based category cards (بيتزا, برغر, ستيك, دولمة, شاورما, إيطالي, مقبلات). Below them, list food items in elegant dark-green cards with glassmorphism effects. Each item must include: Name, Price in 'د.ع', +/- quantity selector, and 'إضافة إلى الطلب' button.
 Contact Section: Title: 'زورونا او اطلبوا', with 4 clear cards for (العنوان: البصرة - أبي الخصيب, للطلبات: 07756000241 / 07878777237, إنستغرام: @japppel, واتساب: direct link).
3. Functionality:
 Add a floating WhatsApp button in the corner.
 Use a smooth scroll animation for all sections.
 Make it fully responsive and fast for mobile users.
 Add a footer: 'مطعم جبل - هنا تجد الطعم كما لم تذقه من قبل ❤️ - جميع الحقوق محفوظة 2026'."
